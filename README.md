# Maa Sharda Vidya Mandir Dhar Backend

Backend server for the Maa Sharda Vidya Mandir Dhar School Website.

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MySQL

---

## 🚀 Features

- Admin Login API
- Notice Management
- Contact Form APIs
- MySQL Database Integration
- REST APIs

---

## ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/harsh085/msvm-backend.git
```

Go to project folder:

```bash
cd msvm-backend
```

Install dependencies:

```bash
npm install
```

---

## 🔧 Environment Variables

Create `.env` file:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=msvm_school
PORT=5000
```

---

## ▶️ Run Server

```bash
npm start
```

Server runs on:

```bash
http://localhost:5000/
```
